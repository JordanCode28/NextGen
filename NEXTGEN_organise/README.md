# NEXTGEN — projet organisé

## Structure

```text
NEXTGEN/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
    └── images/
        └── README.txt
```

## Pour lancer le site

1. Garde cette structure de dossiers.
2. Copie les images d'origine dans `assets/images/`, sans renommer les fichiers.
3. Ouvre `index.html` dans ton navigateur ou utilise Live Server dans VS Code.

## À savoir

- Le CSS est dans `css/style.css`.
- Le JavaScript est dans `js/script.js`.
- Les commentaires sont enregistrés dans le `localStorage` du navigateur : ils ne sont pas partagés entre appareils et ne constituent pas une base de données.
- Le code source fourni ne contenait pas les fichiers images eux-mêmes ; les emplacements sont préparés mais les images doivent être ajoutées.
